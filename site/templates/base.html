Migration Data Ecosystem

A profile of the data sources used to study migration from Latin America and the Caribbean. Every chart is built from small aggregated tables derived from public or publishable sources; no microdata is published here.

Built with Python and Plotly. Last build {{ built }}.

Sources and citations

  • Ruggles et al., IPUMS USA; Flood et al., IPUMS CPS; US Census Bureau, ACS PUMS.
  • Eurostat migration and asylum statistics (migr_*).
  • IDB Social Sector, harmonized household surveys; INE Spain, EPA (via the HDMF project).
  • UN DESA, International Migrant Stock 2024; Azose and Raftery (2019) FLown estimates accessed via Gaskin and Abel (2025); UNHCR Refugee Data Finder; KNOMAD / World Bank.
  • Deportation Data Project (ICE, USCIS and CBP records released under FOIA).
